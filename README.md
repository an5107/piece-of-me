- **Voice recording:** Uses `getUserMedia` and `MediaRecorder` when supported. Recording starts only after an explicit button press, shows a timer and minimal waveform, and can be stopped, replayed, saved, or discarded. Speech recognition waits briefly for the browser's final transcript event before enabling Save. Browser speech-to-text is optional; the captured text is left as recognized and editable, with no intentional profanity filtering or rewriting. Requires a compatible browser, microphone access, and HTTPS or localhost; errors are shown in the interface.
